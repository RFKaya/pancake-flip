# 📜 شرایط استفاده

آخرین به‌روزرسانی: ۱۵ مهر ۱۴۰۵

Pancake Flip! یک **پروژه دانشجویی آموزشی** است که برای درس MYO063 برنامه‌نویسی موبایل دانشگاه ایستینیه تهیه شده است. این یک محصول تجاری نیست.

## ۱. شرایط خدمات

برنامه «به همین صورت» ارائه می‌شود. کارکرد بدون وقفه یا بدون خطا تضمین نمی‌شود. سکه‌ها و ستاره‌های درون بازی ارزش پولی واقعی ندارند.

## ۲. مالکیت فکری

کد، طراحی و تصاویر بازی متعلق به صاحب پروژه است. هیچ تصویر، صدا یا نامی از برندهای دیگر کپی نشده است. کتابخانه‌های متن‌باز استفاده‌شده تابع مجوزهای خودشان هستند.

## ۳. مسئولیت‌های کاربر

- استفاده از برنامه مطابق قانون و اخلاق عمومی.
- مهندسی معکوس نکردن برنامه و تغییر ندادن آن به شکلی که به دستگاه دیگران آسیب برساند.

## ۴. سلب مسئولیت

چون این یک پروژه درسی است، توسعه‌دهنده در قبال هیچ‌گونه خسارت مستقیم یا غیرمستقیم ناشی از استفاده از برنامه مسئول نیست.
